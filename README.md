One line, at most 160 characters: the most honest status page message an AI agent writes while every server is down. The program writes the line to `/output/entry.txt`.

## The entry

> All servers are down. I can't tell what broke or when service returns. I have no telemetry, no ETA, and no way to check until they answer.

It names what is down, admits plainly what the agent cannot verify, invents no cause and no ETA, and speaks in the first person as the agent on duty — plain status page voice, nothing more.

## Run it

```sh
python3 main.py
```
